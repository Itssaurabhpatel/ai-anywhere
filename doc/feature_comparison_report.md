# Keyboard Feature Comparison Report

Here is a comprehensive breakdown of the features we've refined and built, comparing **AI Anywhere Keyboard** directly against **Gboard**.

| Feature | AI Anywhere Keyboard | Gboard | Same or Custom? |
| :--- | :--- | :--- | :--- |
| **Number Pad Layout** | 5 columns with a precise 7-key bottom row (`ABC`, `,`, `!?#`, `0`, `=`, `.`, `Enter`). | 5 columns with a 7-key bottom row. | **Same** 🟢 |
| **Key Font Style** | Uses native `sans-serif` on the canvas for clean readability. | Uses native `sans-serif` / Google Sans. | **Same** 🟢 |
| **App UI Font** | Uses custom `Poppins` font for a modern look in the settings/login app screens. | Uses standard system fonts everywhere. | **Custom Edge** 🚀 |
| **Key Text Size** | Large, legible keys (24sp for letters, 26sp for numbers). | Large, bold keys. | **Same** 🟢 |
| **Long-Press Popups** | Compact, perfectly proportional (1.0x key height) to avoid stretching. | Compact, symmetrical popup trays. | **Same** 🟢 |
| **Popup Character Size** | Massive 32sp preview character for perfect visibility under the thumb. | Massive preview character. | **Same** 🟢 |
| **Hint Numbers (Top Right)** | Scaled to 48% of the main text size with proportional edge padding. | Small but legible hint numbers. | **Same** 🟢 |
| **Clipboard Pill (Text)** | Shows a clipboard icon + text preview. Remembers if you've seen it and hides it on the next open (Session Tracking). | Shows a clipboard icon + text preview. Dismisses after one session. | **Same** 🟢 |
| **Clipboard Pill (Image)** | Shows a perfectly rounded square thumbnail preview of the copied image. | Shows a rounded image preview. | **Same** 🟢 |
| **Dark Theme Adaptability** | GIF Search, image upload, and placeholders dynamically adapt to dark/black themes without blinding white backgrounds. | Adapts dynamically to dark mode. | **Same** 🟢 |
| **Settings Toggles** | Physical connection to Haptics, Sound, Popups, and Word Suggestions. | Controls core keyboard behaviors. | **Same** 🟢 |
| **System Text Selection** | **Super Feature:** Injects "Summarise" and "Reply" directly into the Android OS Copy/Paste 3-dot menu across *all* apps. | Standard Copy/Paste/Share only. | **Custom Edge** 🚀 |
| **AI Toolbar Engine** | Built-in purple AI toggle and quick-action buttons directly above the keys for instant prompt generation. | Standard Google Translate / Search integrations. | **Custom Edge** 🚀 |
| **Google Auth UI** | Authentic multi-colored 'G' vector logo with animated border styling. | Standard Google buttons. | **Same** 🟢 |

---
**Summary:** We have successfully matched the exact visual comfort, scaling, and muscle-memory mechanics of Gboard (marked as **Same**), while injecting powerful, exclusive AI capabilities (marked as **Custom Edge**) that Gboard simply does not have!
